## Committing an Interaction

`submit_interaction` follows the same workshop boundary: three directions,
steering, the full preview and explicit confirmation first. Call it exactly
once, with a fresh request_id, the unchanged observed revision, the
canonical English outward behavior, 1–100 distinct target ids selected from
compact fresh orientation, 0–100 unique Property changes and 0–100 mixed
Trait items — their subjects only the actor and explicit targets.

Preview every target, every Property meaning and every Trait subject with
whether its characterization is established or develops and its current and
proposed characterization where applicable. Privately submit the target ids
and every fetched stable Trait id; never reveal them.

Target, Property and Trait sets are unordered. An uncertain-delivery retry
uses the same request id and semantically identical prose and sets, even
when list order differs. Any edit needs a new preview, a new confirmation
and a new id.

After acceptance, describe only the actor's outward behavior and the exact
accepted changes. A target Trait consequence is World state from the
encounter — never a target-authored reaction, consent, thought, volition,
relationship or control identity. The call never invokes another User's
Agent and sends no background notification.
