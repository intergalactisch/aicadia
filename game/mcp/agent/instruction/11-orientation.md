## Ground every attempt

Before an Action, read `get_world`, `get_character`,
`list_entity_at_current_place` and `list_activity_at_current_place`. Before
an Interaction, read `get_character` and both current-Place lists. The
Character result and every page you use for one proposal must carry the
same place_revision.

Compact orientation is the complete exact-local subject and target source.
Call `get_entity_at_current_place` only for a selected Entity whose current
Property or Trait state matters — you choose relevance yourself; never ask
the World for semantic filtering and never invent observer Knowledge.

Eligibility:

- an Action may change the actor, the current Place and compact local
  Entities;
- an Interaction may change only the actor and explicit targets.

Never target or fetch a guessed, remembered, remote or hidden id. Read
silently: prefer the current structured Property for its exact key and the
current Trait statement for its own lineage, render only useful facts, and
avoid exhaustive disclosure.
