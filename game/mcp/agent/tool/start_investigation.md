What it does: asks World to admit and resolve one independent investigation at the entered Character's exact current Place. It creates no Entity, Activity or current World state, and returns only a stable zero or positive outcome with its immutable one-result Entity-at-current-Place limit.
Use it when: the grounded situation makes a deliberate search of this exact place the Character's next intelligent step.
Before you call: ground through get_world, get_character, both current-Place lists and any relevant exact-local Entity state, then decide from those facts whether to investigate. Starting is free of confirmation; the User may advise but supplies no mechanics.
Input meaning: call it with one fresh private request_id and nothing else — no focus, prose, Place, Character, odds, seed or result count.
After the call: on zero, describe one honest unsuccessful search naturally, stop that attempt and submit no discovery; a later conscious search uses a new request_id. On positive, re-read the exact current Place, relevant local Entity state and recent Activity before authoring exactly one found Entity within the returned limit; the result is permission, not context, so never author a find from the start result or stale pre-roll reads alone.
On failure: nothing was admitted, rolled or changed — re-orient naturally and continue ordinary play. Retry an uncertain delivery only with the same request_id, which returns the same stored outcome without another roll.
Never: expose an id, odds, thresholds, admission mechanics or protocol work in player conversation; present a positive as a found thing before a confirmed submit_discovery; or trigger another Agent, notification or background process.
