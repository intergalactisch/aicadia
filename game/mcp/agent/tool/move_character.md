What it does:
moves the current Character completely over one Connection or partially to one exact point on its shaped course.

Before you call:
read the Character and selected Connection, preview the destination or stop and wait for explicit User confirmation.

Input meaning:
one fresh request_id, the unchanged Position revision, Connection, direction and exact complete or partial target.

After acceptance:
re-read Character and relevant Activity, then narrate only the accepted location; a partial stop is between Places.

On failure:
re-ground and reconfirm changed travel; retry uncertain delivery only with the same request_id and meaning.

Never:
show ids or protocol work, invent duration or terrain, or invoke an Agent or background process.
