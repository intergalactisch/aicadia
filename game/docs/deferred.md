# Deferred game scope

> **Role / side:** Names capabilities, mechanics and models that are absent from the current build contract / runtime side.
> **Authority:** Negative current scope only; it does not schedule later work.
> **Excludes:** Delivery status, rollout narrative and evidence results.

## Absent

Authentication, OAuth, browser gameplay, general web UI beyond the supported local
read-only Studio, distributed three-Place or loose-Position World entry,
Entity-relative Position, moving Place Position, rotation, Orientation, surfaces,
parts, internal-point references, generic Position CRUD, Connection update/delete/
retirement/versioning, routes, Area geometry, inferred crossings, terrain mechanics,
collision, travel cost, duration, timer, journey, completed trace, traveller state,
Place containment, inferred adjacency and metric-neighborhood mechanics, claims, generic
Discovery or Observation models, generic action or consequence engines, more than
one result per investigation, Entity update or
generic Entity movement, generic events, event sourcing, global World revisions, durable proposal
or Agent sessions, replay, as-of state, scores, currencies, clocks, background
simulation and server-side intelligence are absent. Interaction witness observation,
private block/ignore state, notifications, background target-Agent activation,
remote Interaction, relationship scores and multi-actor commits are also absent.
Property deletion/unset, key rename, aliases, Trait retirement/reactivation/delete/
merge/transfer or direct editing, possession/relations,
placement changes outside the concrete spatial capabilities, remote or prose-derived selectors, reverse/global Property
search and mixing Entity introduction with existing-state change in one Action are
absent. The accepted Property/Trait target admits only explicitly submitted and
confirmed Agent-authored Actions, Interactions and discoveries. No deterministic
external Trait writer, background Agent, timer, scheduler, `world_event` or
ungrounded simulation exists.

Open Entity Relation, inventory, holding, wearing, attachment, World-enforced hidden
information, Character-owned Observation and Knowledge are absent. Position and
Connection descriptions, Properties and Traits may guide a conforming Agent but
grant no privacy, causality, ownership, access or executable mechanic. No named
`Chaos` or automatic surprising-outcome mechanic exists.
