# Concept guide

> **Role / side:** navigation index for live exploration and frozen concept history / development side.
> **Authority:** identifies each concept record's theme and where to read it.
> **Excludes:** Each record's own exploration status, which lives in its front matter; current implementation and game behavior, which belong in `game/docs/`; delivery evidence, which belongs in `dev/docs/evidence/`.

Concept records explain rationale and preserve open exploration. They cannot override
the [current game contract](../../../game/docs/README.md). A concept becomes current behavior
only when the owning `game/docs/` contract explicitly accepts it. Each record carries
its own exploration status in its front matter.
