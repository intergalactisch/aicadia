# Methodology

> **Role / side:** index of reusable working methods / development side.
> **Authority:** identifies each method record and where to read it.
> **Excludes:** the methods themselves, product contracts and build rules; see each record, `game/docs/` and `AGENTS.md`.

A method record says how a class of work is done well and repeatably. It never
owns product truth: the contract it serves stays in `game/docs/`, and the compact
rule that invokes it stays in `AGENTS.md`.

## Records

- [Public-facing text](public-text.md) — how text that Aicadia publishes verbatim to Agents and Users is written, changed and checked.
- [Build-facing text](build-text.md) — how the documents a building Agent reads earn their place, state what they own and point to what they do not.
