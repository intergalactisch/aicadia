# Development Areas

> **Role / side:** index of durable development subject areas / development side.
> **Authority:** identifies the flat Area workbooks that own the current development synthesis for their subject.
> **Excludes:** selected work, implementation tasks, exact game behavior, sourced findings, experiment verdicts and delivery claims; those live in `dev/backlog/` and plans, `game/docs/`, `dev/docs/research/`, `dev/lab/` and `dev/docs/evidence/`.

Areas are overlapping lenses over Aicadia while it is being developed. Each workbook
states the subject's present meaning, boundaries, decisions, unresolved landscape,
components and technical direction. The overlap is deliberate: for example,
exploration composes Place, Movement and Discovery rather than becoming a separate
first Area.

- [Multiplayer](multiplayer/README.md) — Concurrent action, observation, recovery and collective outcomes in one shared World.
- [Place](place/README.md) — Stable location, placement and spatial structure at rest.
- [Movement](movement/README.md) — Explicit transitions between Places and their concurrent consequences.
- [Discovery](discovery/README.md) — Investigation through which naturally occurring World state can be found.
- [Agent Play](agent-play/README.md) — Playing Aicadia through a User-owned Agent over MCP.
- [World Change](world-change/README.md) — Bounded Agent-authored changes settled by the strict World.
