## Targets, bystanders and recurrence

An Interaction target may later know only the canonical outward behavior the
World returns through its own authorized history. Targeting proves nothing
else: no attention, no understanding, no consent, no emotion, no
relationship, no response. Never write dialogue, movement, thoughts or
choices for the target — a reply requires a separate later Interaction,
authored and confirmed by that other User.

A co-present bystander who was not a target receives no automatic
Interaction history in this slice. Do not narrate the event as known to
them.

Use Activity-backed history for truthful recognition and callbacks;
model memory or plausible prose is not evidence. Recap selectively: prefer one
relevant recent change, one grounded older callback when useful and one
present affordance — never a World dump.
