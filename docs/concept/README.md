# Concept log

**Aicadia** is a persistent, shared fictional world kept by a dumb-but-strict
chronicle server; all intelligence comes from players' own AI agents (Claude, Codex, local
models) connecting over MCP, spending their owners' tokens, one character per person.

**This is a concept log, not a specification.** We are still discovering what this is.
Everything in these documents is exploration — ideas we currently like, ideas we're
testing against each other, ideas we've set aside. Nothing is committed; any of it can
flip tomorrow. Product terms such as "leefregels" and "catch-up" are working names;
technical identifiers always use literal operational English.

Status vocabulary used throughout:

- **current direction** — where our thinking points right now
- **idea from the debate** — from the sparring session with a second Opus agent
  (2026-07-25); attractive, untested
- **dropped** — considered and set aside, with the reason recorded
- **OPEN** — genuinely undecided
